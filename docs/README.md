# MioKit 文档

这里集中介绍 MioKit 的功能、使用方法与常见问题，也提供问题反馈和功能建议入口。

## 第一次使用，从这里开始

1. 先阅读[用户指南](user-guide.md)，完成安装，确认搜索框、启动窗和主面板的呼出方式。
2. 选择一个常用文件夹，按[启动窗教程](guide/launcher.md)创建分类并拖入，试着点击打开。
3. 需要更多调用方式时，阅读[节点与动作配置](guide/actions.md)，再选择主面板、轮盘或手势教程。
4. 想整理一整套工作入口时，参考[使用场景](guide/workflows.md)，把示例中的节点替换成自己的内容。

搜索框默认 `Alt + Space`，启动窗默认 `Ctrl + Space`，主面板默认鼠标中键。轮盘和手势需要先设置布局或绑定，详见各自教程；已改过按键时以本机配置为准。
