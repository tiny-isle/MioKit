# 贡献指南

欢迎帮助改进 MioKit 的功能介绍、用户文档和插件开发文档。

## 可以贡献什么

- 修正文档中的错误、歧义和失效链接。
- 补充经过确认的功能说明、截图和示例。
- 改进插件开发流程和排错说明。
- 提交功能建议、问题反馈或文档需求。

## 开始之前

1. 先搜索已有的 Issue，避免重复提交。
2. 涉及功能或 API 的内容，应确认对应版本和来源。
3. 不要把未公开的源代码、密钥、用户数据或构建产物提交到本仓库。
4. 对仍未确定的内容，请保留“待补充”标记，不要用猜测替代规范。

## 文档修改原则

- 使用中文为主，术语和 API 名称保持原文。
- 优先使用短句、步骤和可验证的示例。
- 相对链接应指向仓库内实际存在的页面。
- 图片应放入 `assets/images/` 或 `assets/diagrams/`。
- 新增截图时，应避免包含个人信息、密钥和本地路径。

## 提交变更

请创建 Pull Request，并在描述中说明：

- 修改了什么内容。
- 对应的功能或文档版本。
- 是否新增或替换截图。
- 如何验证链接、示例和页面渲染。

问题反馈请使用 [Bug Report](../.github/ISSUE_TEMPLATE/bug_report.md)，功能建议请使用 [Feature Request](../.github/ISSUE_TEMPLATE/feature_request.md)。
