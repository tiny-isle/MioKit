# 贡献指南

本仓库用于 MioKit 的功能介绍、使用说明、问题反馈和功能建议。欢迎补充教程、截图和场景示例，或报告产品与文档问题。

## 可以贡献什么

- 修正文档中的错误、歧义和失效链接。
- 补充经过确认的功能说明、截图和示例。
- 改进使用步骤、常见问题和排错说明。
- 提交功能建议、问题反馈或文档需求。

## 开始之前

1. 先搜索已有的 Issue，避免重复提交。
2. 涉及具体功能、入口或默认配置时，应确认对应版本和实际界面。
3. 不要把未公开的源代码、密钥、用户数据或构建产物提交到本仓库。
4. 对仍未确定的内容，请保留“待补充”标记，不要用猜测替代规范。

## 文档修改原则

- 使用中文为主，产品名称、按键和按钮名称保持准确。
- 优先使用短句、步骤和可验证的示例。
- 相对链接应指向仓库内实际存在的页面。
- 截图放入 `assets/images/`，避免包含个人信息、密钥和本地路径。

### 一篇使用教程应包含什么

先说明功能用来解决什么问题，再写明入口、首次配置、日常操作和结果检查。涉及快捷键时区分默认值与自定义示例；涉及按钮时使用当前界面名称。插件示例须注明先安装并运行相应插件。

新增教程后，同步更新[文档总览](README.md)相关入口。详细功能正文见[产品功能资料](product/README.md)。

## 反馈产品或文档问题

产品问题请提供 MioKit 版本、插件版本（如涉及）、操作入口和最短复现步骤。主面板、轮盘、手势的问题，还应说明触发按钮、修饰键、前台软件，以及使用的是全局还是应用专属配置。

文档问题请附上页面链接、对应段落、当前界面显示内容和期望的说明。例如：“启动窗教程的快捷键与本机默认设置不一致”，并注明是否曾自行更改快捷键。

功能建议尽量提供具体场景：当前要完成什么任务、现在需要哪些步骤、希望简化哪一步。这样更容易判断应改善现有功能，还是补充说明与示例。

## 提交变更

请创建 Pull Request，并在描述中说明：

- 修改了什么内容。
- 对应的功能或文档版本。
- 是否新增或替换截图。
- 如何验证链接、示例和页面渲染。

问题反馈请使用[问题反馈模板](https://github.com/tiny-isle/MioKit/issues/new?template=bug_report.md)，功能建议请使用[功能建议模板](https://github.com/tiny-isle/MioKit/issues/new?template=feature_request.md)。
