# MioKit 产品总览

MioKit 是 Windows 上的效率工作台。它将应用、文件、文件夹、系统入口和插件功能整理为可查找、可复用的节点，再通过搜索框、启动窗、主面板、轮盘和鼠标手势调用。

同一个“项目目录”可以出现在搜索结果、启动窗分类、主面板格子和轮盘扇区中，也可以用一条手势打开。先收录内容，再选择适合自己的调用方式，能够逐步整理出一套常用工作入口。

## 解决哪些日常问题

| 日常情况 | 可以怎样使用 MioKit |
| --- | --- |
| 知道应用或功能名称，但不想翻菜单 | 打开搜索框，输入名称、拼音、缩写或已设置的别名 |
| 同一个项目的应用、目录、文档分散 | 在启动窗建立项目分类，相关内容放在一起 |
| 不同软件需要不同工具 | 配置主面板应用区、轮盘或手势的应用专属动作 |
| 鼠标操作中临时想选一个动作 | 呼出轮盘，观察高亮后松开执行 |
| 每天反复做少量固定动作 | 为节点设置快捷键或简单手势 |
| 每天都打开同一组工作资源 | 将快速启动库中的成员组成启动组合 |
| 一个工具配置后想从多个位置调用 | 从节点面板拖到需要的入口，复用原节点 |

## 五种主要入口

### 搜索框：按名称查找

默认按 `Alt + Space` 呼出，输入关键词后选择结果并执行。结果可以来自应用、系统入口、自定义启动内容以及已运行插件。支持搜索作用域的功能，可以用触发词和 `Tab` 进入专用搜索。

搜索更适合临时查找：用户只需记住大致名称，无需预先给每个内容安排位置。文件搜索覆盖范围由收录内容和搜索插件决定。

### 启动窗：按分类收纳

默认按 `Ctrl + Space` 呼出，左侧选分类，右侧点选图标。可以按项目、用途或生活场景创建分类，把应用、文件夹、文档和插件节点放在一起。

启动窗支持批量拖入本地文件和文件夹、分类与图标排序，以及单独的显示名称和图标。钉住后可保持窗口，方便连续打开内容。

### 主面板：全局与应用动作并排

默认按鼠标中键呼出。上方全局区保留共用节点，下方应用区根据目标软件选择专属配置；未匹配应用时使用通用内容。

主面板可以有多个动作页，支持直接填格子、拖拽、移动和交换。适合在工作过程中查看一组明确的动作，而不是再次输入名称。

### 轮盘：在鼠标周围选动作

先配置圈层和扇区绑定，再按住触发按钮拖动，指向高亮扇区后松开。默认触发按钮为右键，初始没有圈层，需要完成首次配置。

轮盘支持多圈、应用覆盖和子轮盘。需要较多工具时，主轮盘保留高频入口，低频动作放在子轮盘中。

### 鼠标手势：用轨迹直接执行

为轨迹绑定节点后，按住触发按钮绘制，松开执行。默认使用侧键 X1，初始没有动作绑定。

手势支持修饰键、应用绑定、自定义录制、追加样本和识别测试。刚开始使用时还可以保持按住并停顿，先看候选卡片，再选择要执行的动作。

## 配套能力

| 能力 | 与主要入口怎样配合 |
| --- | --- |
| 节点面板 | 搜索和筛选节点，把同一个节点拖到不同入口 |
| 快速启动 | 管理扫描应用、系统入口、手动路径、启动参数和组合 |
| 应用配置 | 主面板、轮盘、手势共享进程资料，分别设置绑定内容 |
| 全局快捷键 | 为支持的节点直接设置组合键，集中管理已有快捷键 |
| 上下文 | 支持的动作使用目标窗口、剪贴板或资源管理器信息 |
| 插件 | 增加搜索、节点、操作和工具界面，继续使用同一套调用入口 |
| 个性化 | 调整明暗、色板、窗口行为、自启动与全屏响应 |

## 第一次使用建议

1. 安装 MioKit，在首次启动中选择数据位置和主题。
2. 点击 **开始使用**，等待准备完成，再点击 **重启并进入**。
3. 按 `Alt + Space` 搜索一个熟悉的应用，确认可以执行。
4. 按 `Ctrl + Space` 建立“常用”分类，拖入一个文件夹，按提示添加后点击打开。
5. 按鼠标中键打开主面板，把同一个文件夹节点放入全局区。
6. 确认两种入口都顺手后，再配置轮盘、手势或应用专属内容。

默认按键可以调整。安装过旧版本、已经自行设置或遇到快捷键冲突时，应以本机保存的值为准。

## 功能范围与使用前提

节点能够参与搜索、能够执行、能够使用快捷键，属于不同能力。不能仅凭节点有名称就认为它一定可以全局搜索，也不能把所有管理或展示项都当作可执行动作。

剪贴板管理、快速输入、Everything 搜索等具体工具取决于对应插件。使用前应安装并运行插件，必要时先在插件内创建条目；本文不表示所有示例工具均默认附带。

启动组合用于一起发起启动库成员的调用，不保证完成顺序，也不提供等待、延时或任意插件动作编排。多入口复用指向同一个节点，不会把一个节点复制成几套独立数据。
