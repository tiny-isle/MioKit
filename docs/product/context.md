# 操作目标与上下文

部分动作只需知道节点内容，例如打开固定文件夹；另一些动作还需要知道要操作哪个窗口、当前复制了什么、资源管理器在哪个目录。这些与本次调用相关的信息称为上下文。

MioKit 为支持的功能提供相关调用信息，具体是否使用、如何处理，由节点或插件决定。上下文不是保证任意节点都能自动读取任意软件内容的承诺。

## 三个容易混淆的概念

| 概念 | 回答的问题 | 示例 |
| --- | --- | --- |
| 节点内容 | 要执行什么 | 打开某个固定项目目录 |
| 应用配置 | 本次显示或选择哪组动作 | 浏览器与编辑器使用不同轮盘槽位 |
| 操作目标 | 对哪个实际窗口执行 | 将文本输入刚才使用的编辑器窗口 |

为多个软件共用一组配置，只是共用动作，不会把它们的输入目标改为配置名称所指的另一款软件。主面板锁定场景也只固定格子集合，不冻结后续操作目标。

## 不同入口怎样确定窗口

| 入口 | 用户应怎样操作 | 需要留意 |
| --- | --- | --- |
| 启动窗 | 先回到要操作的软件，再按启动窗快捷键 | 标题栏显示本次操作目标 |
| 主面板中键 | 将指针放在要操作的软件窗口内，再按中键 | 按下位置所在窗口用于识别应用与目标 |
| 主面板键盘快捷键 | 先激活目标软件，再用快捷键呼出 | 使用前台软件作为目标 |
| 轮盘 | 在目标软件窗口内按住按钮开始拖动 | 开始触发的位置决定目标 |
| 鼠标手势 | 在目标软件窗口内按下按钮开始绘制 | 开始绘制时确定目标和修饰键 |

拖动期间指针经过别的窗口，不应被当作随意重选本次目标的方法。需要换目标时，取消当前操作，回到另一个软件重新触发。

## 哪些动作依赖目标窗口

打开固定程序、目录或文档，通常只使用节点自身保存的路径。快速输入、向当前软件输入内容、处理选中文本等动作，可能需要有效的目标窗口和相应插件支持。

目标窗口已经关闭、被替换或无法激活时，按错误提示重新回到目标软件再触发。不要期待它自动转而向某个无关的前台窗口执行。

## 剪贴板上下文

搜索框的 **自动粘贴** 设置提供禁用以及 3、5、10、15、20、30 秒时间窗口，用于决定最近复制的内容是否参与相应上下文。它不是无条件把剪贴板输入到所有软件。

在支持条件下，搜索可根据复制内容提供文本、图片、单个文件、文件夹或多个文件相关入口，能执行哪些附加处理取决于支持该类型的功能和插件。

### 一个基本流程

1. 在原软件复制文字，或在资源管理器复制文件。
2. 在配置的有效时间窗口内呼出搜索框。
3. 检查显示的剪贴板相关内容和可用操作。
4. 选择支持当前类型的处理动作，并观察结果。

看不到内容时，检查自动粘贴是否禁用、时间是否已经超过、复制内容类型是否受支持。复制后停留很久再呼出，不应期待始终保留同一上下文。

## 剪贴板上下文与历史管理的区别

当前上下文关注这次调用可使用的复制内容。剪贴板历史插件关注已经记录的多条历史数据，以及它提供的搜索、分类或输入等功能。

启用当前上下文不等于已经安装历史管理工具；安装历史插件后，它的数据保存和具体操作仍按插件自身设置进行。

## 退格与搜索范围返回

输入为空时按 `Backspace`，若当前有剪贴板上下文，会先解除它；文本上下文还可能把文本放进搜索输入。此时先清空新输入，再按 `Backspace` 才能解除附加搜索范围。

因此，“清空输入 → 退格返回”需要结合当时是否有剪贴板上下文观察，不能认为一次退格总会离开所有状态。

## 资源管理器信息

支持的节点或插件可以结合资源管理器当前位置或选中文件处理，例如在当前目录打开终端、对选中文件提供操作。使用时先让资源管理器处于预期目录，完成选择，再调用相应功能。

不能因为在其他窗口中调用了同一节点，就认为仍会获得之前那个资源管理器窗口的目录。节点是否提供该能力，以及多窗口时如何选择，应以该功能的说明和实际提示为准。

## 钉住窗口时的注意事项

钉住启动窗或主面板便于连续使用，但“窗口一直显示”不代表所有动作的数据和目标也永远相同。主面板在未锁定场景时可以跟随软件更新；锁定场景保留的是工具组。

连续执行输入类动作时，每次先确认实际目标。目标已经失效时重新呼出；仅打开固定资源的节点可按其自身内容执行。

## 场景：在阅读时调用输入工具

将已安装输入插件提供的可执行节点放入轮盘。阅读软件内需要输入时，把鼠标放在该窗口内呼出轮盘并执行；切到另一软件时重新触发。多个软件可以共用同一绑定，但输入对象仍按每次实际目标确定。

## 常见问题

**为什么同一动作换软件后结果不同？** 先区分应用绑定是否变化，以及节点是否使用当前窗口或剪贴板。

**工具组已经锁定，为什么操作目标仍变化？** 锁定只固定格子集合，需要操作的软件仍要主动确定。

**节点提示目标不可用？** 回到有效的目标窗口重新触发；同时检查插件是否运行、节点是否仍存在。
