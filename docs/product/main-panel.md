# 主面板与应用动作

主面板把常用节点放入随时呼出的格子窗口。上方全局区提供共用入口，下方应用区显示目标软件对应的动作，适合工作中直接看图标点选。

面板本身置顶，默认按鼠标中键呼出。它既可以短暂出现、执行后隐藏，也可以钉住保持显示，作为工作中的工具面板。

## 默认状态

| 项目 | 默认值 |
| --- | --- |
| 启用主面板、中键呼出 | 均开启 |
| 中键修饰键 | 无，直接按中键 |
| 键盘呼出快捷键 | 没有预设，可单独配置 |
| 布局 | 4 列，全局区 3 行、应用区 4 行 |
| 格子尺寸 | 标准 |
| 显示位置 | 鼠标位置 |
| 失焦后隐藏、执行后隐藏 | 均开启 |
| 循环切换动作页 | 开启 |
| 全屏时禁用 | 关闭 |
| 排除进程、全屏例外 | 初始为空 |

这组布局每页可显示 12 个全局格子和 16 个应用格子；可通过行列与动作页调整容量。

## 第一次添加节点

1. 在日常使用的软件窗口上按鼠标中键，呼出面板。
2. 点击全局区空格子，在选择器中找到常用目录或应用。
3. 确认后点击该格子，检查执行效果。
4. 连续整理时打开标题栏的节点面板按钮，将其他节点拖到空格子。

运行中的面板在场景尚无动作页时，点击空位或拖入可以自动创建默认页。到动作配置集中整理时，则先创建、命名需要的动作页，再填入节点。

本地文件或文件夹也可直接拖到一个格子：已收录路径直接绑定，新路径确认名称与路径后保存添加。每个格子一次接收一个本地项目。

## 全局区、通用区与应用专属区

| 配置 | 何时出现 | 放什么合适 |
| --- | --- | --- |
| 全局 | 上方始终显示 | 常用目录、共用工具、插件管理入口 |
| 通用 | 没有匹配应用时出现在下方 | 其他软件中通用的一组动作 |
| 应用专属 | 匹配目标软件时替换下方内容 | 该软件对应的项目资料和常用工具 |

应用专属区不会自动叠加通用区。希望任何软件中都能看见的节点应放全局区，而不是只放通用区。

## 创建和选择应用场景

可以在 **动作配置 → 主面板 → 节点绑定** 添加应用并选择匹配进程，再整理其动作页。主面板底部也提供 **为当前应用创建场景** 与程序选择入口，方便从正在使用的软件开始配置。

中键呼出时，以按下位置所在的外部软件窗口识别场景；键盘呼出时，以当前激活的软件为目标。使用中键时先把指针放进目标窗口，用键盘时先激活目标软件。

应用资料可与轮盘、手势共用，详见[节点与动作配置](nodes-and-actions.md)。

## 钉住与锁定场景

**钉住面板** 暂停失焦后隐藏和执行后隐藏。主面板本身已经置顶，钉住主要决定是否保持显示。

保持显示时，切换软件仍可让应用区更新。希望始终保留某组格子时，使用应用区标题旁的 **锁定当前场景**，或在场景菜单中手动选择场景；恢复跟随时选择 **自动匹配当前应用**。

锁定固定的是动作集合，不会把后续输入操作的目标永远固定为原软件。需要向具体软件输入或处理内容时，仍要确认当时的操作目标。

## 动作页管理与翻页

全局、通用和每个应用的专属配置都有各自的动作页，可以按“常用”“项目”“工具”命名。

- 在面板对应区域的页面菜单中添加动作页、重命名当前页或删除当前页。
- 已有动作页时最后一页不能删除；新建应用场景可能暂时还没有动作页。
- 到动作配置中可以复制动作页、拖动页签排序，并集中整理格子。
- 使用分页按钮、页面菜单，或在格子区滚动鼠标滚轮切换该区域的页面。
- 焦点位于格子时，用方向键移动，`PageUp` / `PageDown` 切换所在区域的页；`Esc` 隐藏面板。

删除动作页会同时移除其中的绑定，原节点仍保留。全局区和应用区翻页互相独立。

## 拖拽整理与显示定制

将已有格子拖到空位会移动，拖到已有绑定位置会交换。跨页时可以拖到分页箭头上停留，翻页后再放入，也可用右键 **移动 / 交换到其他页**。

右键还可替换节点、修改显示名称或移除面板绑定。动作配置的绑定属性可分别调整名称、描述和图标，修改后点击该区域 **保存**。图片选择支持 PNG、JPG/JPEG、ICO、WebP，也可恢复原节点图标。

## 布局与呼出配置

进入 **动作配置 → 主面板 → 基础设置**：

| 设置 | 范围或选项 | 作用 |
| --- | --- | --- |
| 列数 | 1–12 | 全局区和应用区共用 |
| 两个区域的行数 | 分别 1–12 | 控制每页可见格子 |
| 格子尺寸 | 紧凑、标准、宽大 | 通过配置改变格子和窗口尺寸 |
| 显示位置 | 鼠标位置、屏幕中央、上次位置 | 超出屏幕时限制在可用区域 |
| 中键修饰键 | Ctrl、Shift、Alt，可多选 | 按完整配置组合呼出 |
| 键盘快捷键 | 自定义组合 | 在录入面板单独保存 |
| 失焦后隐藏、执行后隐藏 | 开关 | 未钉住时控制自动收起 |
| 循环切换动作页 | 开关 | 翻过首尾时是否循环 |
| 全屏时禁用 | 开关 | 避免全屏环境呼出 |
| 排除进程 | 指定程序 | 这些程序中不响应呼出 |
| 全屏例外 | 指定程序 | 允许例外程序在全屏禁用开启时呼出 |

基础设置草稿需点击 **保存设置**。减少行列只隐藏超出范围的格子，恢复原容量后可以重新看到；窗口容量主要通过配置调整，不以拖边框任意缩放为操作方式。

全屏例外不会绕过排除进程。中键多选修饰键时需要同时按下完整组合，避免把示例 `Ctrl + 中键` 当作默认值。

## 场景与排查

为编辑器创建专属动作页，下方放项目文档与开发工具，上方保留常用目录；钉住面板后切到阅读软件，下方会换为阅读工具。如果希望切换后仍保留编辑器动作，应在切换前锁定编辑器场景；已经切换时，可以从场景菜单手动选择编辑器场景。

呼出失败先查启用状态、实际按键、中键修饰键、全屏限制和排除进程。应用区不对时检查锁定状态、进程匹配和触发位置；布局缩小后缺少节点时恢复行列或切回原动作页。
