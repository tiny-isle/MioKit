# 鼠标手势与候选选择

鼠标手势通过“按住按钮、绘制轨迹、松开”调用节点。记住少量轨迹后，无需先打开菜单；暂时不确定结果时，可以画完保持按住，停顿查看候选后再选择。

手势可绑定目录、应用、文档或插件提供的可执行节点，没有预设“向左必定后退”等固定规则。

## 默认配置

| 项目 | 默认值与范围 |
| --- | --- |
| 启用手势 | 开启 |
| 触发按钮 | 侧键 X1；可选右键、中键、X1、X2，同时只使用一个 |
| 执行阈值 | 80%；可调 0%–100%，步长 1% |
| 候选停顿 | 800 毫秒；可调 100–10000 毫秒，步长 100 毫秒 |
| 内置轨迹 | 上、下、左、右、右上、左上、右下、左下，默认启用 |
| 动作绑定 | 初始为空，需自行选择节点 |

## 第一次绑定与执行

1. 托盘右键打开 **动作配置 → 鼠标手势 → 基础设置**。
2. 确认启用和触发按钮，保留初始识别参数并点击 **保存设置**。
3. 进入 **节点绑定**，选择左侧 **全局**，选中内置手势 **上**。
4. 在 **无修饰键** 行选择一个常用文件夹；也可以双击选择或从节点面板拖入。
5. 将鼠标放进日常使用的软件窗口，按住所选触发按钮（默认 X1）向上绘制清楚的一段，再松开。
6. 检查目标文件夹是否打开，然后再增加其他动作。

轨迹过短不会执行。绘制期间按 `Esc` 可取消。没有侧键时，到基础设置选择其他按钮，并与轮盘、主面板分开安排。

## 两种执行方式

### 画完直接松开

系统比较轨迹，最佳候选达到执行阈值并有可用绑定时自动执行。适合熟悉、容易区分的简单轨迹。

调高执行阈值需要更准确，调低则更容易匹配，也更容易混淆。先通过识别测试区分轨迹，再考虑调整参数。

### 停顿查看候选后选择

1. 画完继续按住触发按钮，并停止移动。
2. 等待候选卡片出现，默认约 800 毫秒，最多显示五个候选。
3. 查看动作名称、手势名称和匹配度。
4. 将指针移到需要的卡片上，再松开触发按钮。

候选出现后的移动用于选卡片，不继续延长原轨迹。在卡片外松开、选择未绑定动作的候选或按 `Esc`，都不会执行。

主动选择候选不再要求达到自动执行阈值。因此不能将 80% 解释为所有手势调用的绝对门槛。

## 用修饰键扩展轨迹

每条轨迹可分别绑定无修饰键、Ctrl、Alt、Shift、Win，以及它们的组合，共 16 种状态。点击 **添加修饰键** 选择组合，再为该行设置节点。

例如，无修饰键的 **上** 打开项目目录，`Ctrl + 上` 打开需求文档。使用第二个动作时，先按住 Ctrl，再按鼠标触发按钮开始画，最后松开鼠标执行。

本次修饰键组合在按下鼠标时确定，中途补按不会改换本次动作。未绑定的组合不会自动改用无修饰键动作。

同一轨迹的修饰键行之间可拖动整理：到空行移动，到已有绑定的行交换。跨轨迹整理应重新选择目标轨迹并设置，不能把任意行都当成同一拖拽范围。

## 为软件设置专属动作

在左侧添加应用并配置进程，选择它，再设置特定轨迹与修饰键行。应用绑定优先，未设置时回退全局相同轨迹和完整组合。

编辑页展示应用自己的绑定。清除应用 `Ctrl + 上` 后，仍可能执行全局 `Ctrl + 上`；不会回退到全局无修饰键的 **上**。

应用根据开始绘制时鼠标所在的软件窗口匹配。关联程序共用的是配置，实际调用目标仍是触发时的那个窗口。

## 录制自定义手势

1. 点击 **新增手势**，填写容易识别的名称。
2. 在录制画布中按住 **鼠标左键** 绘制，松开结束。
3. 不满意时点击 **重画**，绘制中可以按 `Esc` 取消当前笔画。
4. 保存前可用 **识别测试** 查看与已有轨迹是否混淆，但尚未保存的新轨迹不在候选库中。
5. 点击 **保存**，再从 **手势属性 → 识别测试** 绘制一次，确认能匹配新手势。
6. 给它绑定节点，回日常软件用设置的触发按钮验证。

录制画布使用左键，日常触发使用基础设置中的按钮，两者操作场所不同。

## 样本、启停与删除范围

| 操作 | 内置手势 | 自定义手势 |
| --- | --- | --- |
| 启用、停用和识别测试 | 支持 | 支持 |
| 修改名称 | 不支持 | 支持 |
| 重新录制 | 不支持 | 支持，替换原样本 |
| 追加样本 | 不支持 | 支持，为同一手势增加日常画法 |
| 删除 | 不支持 | 支持，同时删除所有应用中的对应绑定 |

轨迹库、名称、样本和单条启停是所有应用共用的。左侧切应用只改变节点绑定范围，不会复制一套独立手势库。停用轨迹会影响所有应用。

识别不稳时先查看是否总混淆到某条相似轨迹。优先让形状差异更明显，再追加符合日常画法的样本；不必一开始录制大量相近轨迹。

## 常见问题

**画了却没执行？** 查轨迹长度、手势是否启用、当前组合与应用绑定、节点可用性，以及直接执行的阈值。

**候选出现却取消了？** 需要指向已绑定动作的卡片再松开，卡片外松开表示取消。

**Ctrl 组合不对？** 先按 Ctrl，再按鼠标开始画，并检查全局同一组合的回退。

**临时要恢复鼠标原来的拖动？** 关闭基础设置中的 **启用手势** 并保存，后续开启会保留轨迹和绑定。
