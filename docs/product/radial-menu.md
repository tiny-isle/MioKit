# 多圈轮盘与子轮盘

轮盘把可执行节点放在指针周围的扇区中。按住触发按钮并拖动，轮盘出现后移动到高亮扇区，松开执行。适合已经在使用鼠标、希望看一组动作再选择的情况。

## 默认配置与首次使用

轮盘默认启用，触发按钮是 **鼠标右键**，拖动阈值 **8**。初始没有圈层，需先配置可见圈和槽位，再添加动作；仅开启开关不会自动生成一套工具。

1. 托盘右键打开 **动作配置 → 轮盘 → 基础设置**。
2. 保留右键或选择其他触发按钮，设置至少一个可见圈层，并保证该圈槽位数大于 0。
3. 点击 **保存设置**。
4. 切到 **节点绑定**，选择左侧 **全局**，给一个扇区选择节点，或从 **全部节点** 拖入。
5. 将鼠标放进要操作的软件窗口，按住触发按钮并移动，指向绑定位置后松开。

先绑定一个能直接打开的文件夹，便于确认触发和执行都正常。

## 选择、执行与取消

按住后必须移动超过拖动阈值。只短按、未达到触发距离时保留普通鼠标点击；轮盘出现后，松开时命中的位置决定执行哪个动作。

取消可以按 `Esc`，或回到中心空白区域后松开。不要依赖“把指针拖出图形”取消：指针在外侧仍可能按方向命中最外圈。圈间空隙和扇区空隙不会命中动作。

## 全局布局与配置项

触发按钮和圈层布局由所有应用共用。应用配置改变槽位内容，不为不同软件单独建立另一套圈宽或触发方式。

| 设置 | 可选值或范围 | 初始或新圈默认值 |
| --- | --- | --- |
| 启用轮盘 | 开、关 | 开 |
| 触发按钮 | 鼠标右键、中键、侧键 X1、侧键 X2 | 右键 |
| 拖动阈值 | 1–128 | 8 |
| 显示圈数 | 0–16 | 初始无圈层 |
| 中心半径 | 0–2000 DIP | 48 |
| 圈间距 | 0–2000 DIP | 0 |
| 圈名称 | 自定义文字 | 第 N 圈 |
| 每圈槽位数 | 0–64 | 新圈 8 |
| 圈宽 | 1–2000 DIP | 新圈 82 |
| 起始角 | −360° 至 360° | 新圈 −90° |
| 扇区间距 | 0°–45°，步长 0.5° | 0° |

DIP 是随系统缩放调整的界面尺寸单位。第一次不必修改所有参数，先用少量槽位并将常用动作放在容易区分的方向，再通过预览调整间距。

轮盘触发按钮不提供组合修饰键条件。示例中的 X2 需要自行配置，不能直接把 `Ctrl + X2` 当作同一设置支持的选项。

## 圈层显示、隐藏与删除

点击圈层标签或预览圈层，选择当前编辑对象。**显示到此圈** 会显示它及所有内圈；**从此圈起隐藏** 会隐藏它及外圈。

减少显示圈数或槽位数，会保留超出范围的绑定，恢复后可再次使用。删除圈层并保存则会删除全局、各应用及各子轮盘中这一圈的绑定；保存基础设置也会重置撤销历史。

修改后点击 **保存设置**，回实际软件观察布局，再确认熟悉的方向没有偏移。

## 应用覆盖与运行时三页

在动作配置左侧添加应用、选择匹配进程，然后只为需要变化的槽位绑定节点。相同位置有应用绑定时优先应用动作，没有时使用全局。

编辑画布显示所选应用自己的绑定，因此空槽位不一定表示运行时没有动作。实际取得应用轮盘配置后，主轮盘有以下三页：

| 页顺序 | 显示内容 |
| --- | --- |
| 第一页 | 全局内容 |
| 第二页 | 应用与全局合并，默认进入此页 |
| 第三页 | 仅应用专属内容 |

向上滚轮切前一页，向下切后一页，首尾不循环；中心下方圆点表示当前位置。未取得匹配应用的轮盘配置时，只显示全局这一页。

例如全局左侧打开项目目录，右侧打开通用工具；阅读软件只覆盖右侧，合并页中的左侧仍保持原目录。

## 用子轮盘组织更多动作

1. 在轮盘节点绑定中打开 **子轮盘** 管理。
2. 新建“项目工具”，进入后配置内部扇区。
3. 通过上方路径回主轮盘，选中入口位置，点击 **选择子轮盘** 并选定。
4. 运行时按住按钮呼出主轮盘，指向“项目工具”并松开，进入子轮盘。
5. 用左键点击内部动作；左键点击中心返回上级，`Esc` 取消。

子轮盘不是悬停即展开。它可以被多个入口复用，内部内容由这些入口共用，不再按当前应用叠加另一套内部绑定。

管理列表可新建、重命名、复制、打开编辑或删除。仍被引用的子轮盘不能删除，不能直接或间接引用自身。需要不同内容时先复制，而不是修改所有入口共用的原件。

## 整理与维护

绑定可拖到空扇区移动，或拖到已有绑定的扇区交换。入口名称、描述和图标可在属性区单独设置并保存；图片支持 PNG、JPG/JPEG、ICO、WebP，也可恢复原节点图标。

暂时需要原本的鼠标拖动时，关闭 **启用轮盘** 并保存；重新开启保留原有布局与绑定。

## 场景与常见问题

阅读时把目录、文档和插件工具放一圈；“更多工具”指向子轮盘。在阅读软件中只覆盖特有工具槽位，其他方向保留全局动作。

**不出现？** 查触发按钮、拖动距离、可见圈数和槽位数。**高亮却不执行？** 查槽位绑定与节点可用性。**删除应用动作后仍执行？** 查全局回退和当前页。**容易误触？** 调大阈值，或改用空闲侧键，并分别测试手势和主面板的按钮占用。
