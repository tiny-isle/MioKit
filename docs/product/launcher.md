# 启动窗与分类收纳

启动窗是一块可以随时呼出的分类图标面板。左侧管理分类，右侧显示所选分类中的节点，适合将“一个项目需要什么”或“某种任务常用什么”整理在一起。

它可以收纳应用、文件夹、文档、系统入口和插件提供的可执行节点。部分界面使用“启动器”名称，指向同一功能。

## 呼出与隐藏

默认快捷键是 **`Ctrl + Space`**。已经显示且处于活动状态时，再按该组合可以隐藏；正在使用其他窗口时，快捷键可重新激活启动窗。

修改入口为 **托盘右键 → 设置 → 启动窗设置 → 呼出快捷键**。点击当前快捷键，在录入面板输入新组合并点击 **保存**。

已有自定义值会保留。首次分配默认组合时如果检测到冲突，可能仍显示未设置，应在该页面重新录入一个可用组合。

## 建立第一个分类

1. 呼出启动窗，点击左下角 **添加分类**。
2. 输入“项目 A”，选择容易辨认的分类图标，点击 **保存**。
3. 选中分类，在右侧添加节点或拖入内容。
4. 点击图标执行，确认目录或应用正确打开。

右键分类可以修改名称和图标，或删除分类。按住分类左侧图标上下拖动可调整顺序。删除分类会移除这一组入口，原节点与磁盘文件仍保留。

## 三种添加内容的方法

### 从已有节点中选择

选中分类，在右侧内容区打开右键菜单，点击 **添加节点**，搜索并选择目标。选择器只显示当前可执行且尚未加入该分类的节点，同一节点可以出现在不同分类中。

### 从节点面板拖入

点击侧栏 **节点面板**，在置顶小窗搜索或按类别筛选。将节点拖到右侧内容区，松开后加入当前分类。

插件工具与路径节点使用相同方法。例如先安装并运行快速输入或剪贴板插件，再将它实际提供的可执行节点放进“常用工具”。

### 从资源管理器批量拖入

1. 先选中目标分类。
2. 在资源管理器中选中一个或多个文件、文件夹。
3. 拖到启动窗内容区，看到 **添加到当前分类** 后松开。
4. 已收录项目会直接添加，当前分类已有的节点会跳过。
5. 新路径在添加窗口中检查名称、路径，点击 **保存并添加**。

批量导入可能分阶段完成。取消后续确认不会移除已成功添加的内容；部分项目失败时，只需修正剩余项目并重试。

## 整理图标与单独定制

拖动分类内图标可以调整顺序。右键启动项可修改名称、修改图标或删除这个入口。

显示名称只影响当前分类中的卡片。可以将同一个节点在两个项目里显示为不同简称；留空保存可恢复原名称，不会重命名文件。

自定义图片支持 PNG、JPG/JPEG、BMP、WebP，最大 **2 MB**。选择后预览并保存；使用 **恢复默认** 后也要保存。该图标仅用于当前入口；不要将启动组合图标上传的格式与大小规则套用到这里。

窗口较窄时侧栏自动收起，需要先加宽窗口才能展开。也可以在宽窗口中手动收起侧栏，增加右侧内容空间。

## 窗口设置与默认值

设置位置为 **设置 → 启动窗设置**。开关和下拉选项直接保存；位置模式会在下次呼出时使用，快捷键在录入面板单独保存。

| 设置 | 选项或默认行为 | 使用说明 |
| --- | --- | --- |
| 打开位置 | 屏幕居中、屏幕上方 1/5、屏幕上方 1/4、按屏幕记住位置；默认居中 | 在鼠标所在屏幕打开，可分别记住不同屏幕位置 |
| 记住窗口大小 | 默认开启 | 重启后保留；没有记忆大小时以 800 × 600 为基础，小屏自动适配 |
| 重置位置和大小 | 手动操作 | 下次打开使用重置后的布局 |
| 单元格大小 | 紧凑、标准、宽松；默认标准 | 同时影响格子和图标尺寸 |
| 图标圆角 | 默认开启 | 包括自定义图片 |
| 背景模糊 | 默认关闭 | 开启系统亚克力效果与相应半透明表面 |
| 失焦自动隐藏 | 默认开启 | 未钉住时，转到其他窗口后收起 |
| 启动成功后隐藏 | 默认开启 | 未钉住且节点调用成功后收起 |
| 记住上次分类 | 默认开启 | 跨重启保留；关闭后打开第一个分类 |

## 钉住与连续使用

点击右上角钉住按钮，会让启动窗置顶，并暂时暂停失焦自动隐藏与启动成功后隐藏。适合连续打开编辑器、目录、文档，或对照其他窗口整理内容。

取消钉住后恢复设置中的隐藏规则。手动隐藏启动窗会解除本次钉住状态，下次需要保持显示时再次钉住。

## 输入类节点与操作目标

打开普通应用或文件，不要求先确定某个输入窗口。输入文本、处理选区等动作则可能使用呼出前的目标软件。

先回到要操作的软件，再用快捷键呼出启动窗；标题栏显示本次操作目标。目标窗口已经关闭或失效时，应重新确定目标并重新呼出，不沿用之前那次调用。

## 场景：项目资料集中收纳

建立“项目 A”分类，添加编辑器、项目目录和需求文档。最高频内容放在前面，临时资料放后面；每天用 `Ctrl + Space` 呼出并点选。要连续打开时钉住窗口，要一起发起启动时另建[启动组合](quick-launch.md#创建与维护启动组合)，再把组合放入分类。

## 常见问题

**拖不进去？** 先确认分类已建立且选中，关闭未完成的选择或导入窗口。

**为什么删除图标后搜索还能找到？** 删除的是分类入口，原节点仍存在。手动文件和文件夹可到自定义启动修改，扫描应用、系统入口和插件节点应到各自管理页面处理。

**为什么图标名称在别处没变化？** 这里定制的是当前入口显示，各位置可以保留不同名称和图标。

**为什么钉住后不自动收起？** 钉住会暂停两项自动隐藏设置，取消钉住后恢复。
