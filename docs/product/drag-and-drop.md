# 节点面板与便捷拖拽

拖拽可以将“找到功能”与“安排入口”衔接起来。已有节点从节点面板拖到目标位置，本地文件和文件夹从资源管理器拖入；完成后再通过各入口执行。

节点拖入会创建引用，文件导入会收录或复用启动节点。拖入本身不立即运行内容，也不会把来源节点从原位置移走。

## 节点面板是什么

节点面板是一个置顶小窗，切换目标窗口后仍保留，方便连续搜索与拖出。可以输入关键词、按类别筛选、查看类别数量、刷新和翻页。初始不限分类，每页显示 10 项。

它用于寻找可复用节点，不应把它理解为另一份只包含应用的启动列表。动作入口只接受当前可执行且可用的节点，其他类别是否能拖入，取决于目标要求。

## 四个打开位置

| 当前所在界面 | 打开方式 |
| --- | --- |
| 搜索框 | 搜索 **节点面板** 并执行 |
| 启动窗 | 点击侧栏 **节点面板** |
| 主面板 | 点击标题栏节点面板按钮 |
| 动作配置 | 点击右上角 **全部节点** |

插件刚启动、内容刚创建却找不到时，先刷新，或清空类别与搜索条件再查找。

## 从找到节点到完成绑定

1. 打开目标窗口，选好分类、应用范围、动作页、子轮盘或手势。
2. 打开节点面板，搜索名称或使用类别缩小范围。
3. 按住目标节点，拖到具体落点。
4. 观察接收提示后松开，检查目标位置显示的名称与图标。
5. 继续拖入其他节点，完成后回到实际软件触发一次。

同一个目录节点可以分别放进启动窗、主面板与轮盘。无需为了每个入口重复手动收录路径。

## 已有节点的目标矩阵

| 落点 | 结果 | 拖入前需要确定 |
| --- | --- | --- |
| 启动窗右侧内容区 | 添加到当前分类 | 分类已建立且被选中 |
| 主面板格子 | 绑定到该格子 | 全局或应用区、当前页 |
| 动作配置的主面板格子 | 保存格子绑定 | 左侧配置范围、动作页 |
| 动作配置的轮盘扇区 | 保存扇区绑定 | 全局或应用、当前主轮盘或子轮盘 |
| 动作配置的手势行 | 保存轨迹和修饰键组合的绑定 | 当前轨迹与具体组合行 |
| 支持节点拖入的插件界面 | 按插件规则处理 | 插件明确支持的类型与位置 |

轮盘和手势的直接运行界面不是所有配置落点的替代品；整理绑定时，应进入对应的节点绑定画布或行。

## 本地内容的目标矩阵

| 内容 | 目标 | 数量与后续操作 |
| --- | --- | --- |
| 文件、文件夹 | 启动窗内容区 | 支持多个；已有项加入、重复项跳过、新项确认保存 |
| 文件、文件夹 | 主面板单个格子 | 每次一个；已有路径直接绑定，新路径保存并添加 |
| 文件、文件夹 | 动作配置单个槽位 | 每次一个；绑定到选定配置与位置 |
| 文件、文件夹 | 自定义启动页 | 支持多个，在编辑窗口逐标签检查并保存全部 |
| 文件夹 | 扫描配置的自定义扫描目录 | 支持多个，添加扫描规则后按需重新扫描 |
| `.nupkg` 插件包 | 手动安装中的本地插件包区域 | 每次一个，继续完成来源与安装确认 |

把文件夹添加为启动项，是为了打开它；把文件夹添加为扫描目录，是为了发现其中的应用和快捷方式。把插件包拖进启动窗也不等于安装插件，安装应使用专门区域。

## 新路径确认与批量结果

将文件或文件夹拖到启动窗、主面板或动作配置槽位时，会先匹配已收录启动节点。已有路径直接复用，新路径打开添加窗口，检查名称和路径后点击 **保存并添加**。导入后可到自定义启动页补充适用的参数或工作目录。

启动窗批量导入可能先加入已存在节点，再确认新项目。部分失败时窗口保留待处理项目，已完成部分不用再次添加；取消剩余窗口也不会撤销已成功结果。

## 拖动已有内容整理位置

| 界面 | 支持的整理方式 |
| --- | --- |
| 启动窗 | 分类图标上下排序，分类内图标排序 |
| 主面板 | 空位移动，已有位置交换；悬停分页箭头跨页或右键移动/交换 |
| 主面板动作配置 | 格子移动交换，动作页标签排序 |
| 轮盘动作配置 | 空扇区移动，已有扇区交换 |
| 手势动作配置 | 同一轨迹的修饰键行之间移动或交换 |

不要将“从节点面板添加一个节点”与“移动已有绑定”混为同一操作。前者建立新引用，后者整理现有内容的位置。

## 移除、撤销与修改原内容

只是不需要某个入口时，移除分类卡片或清除格子、扇区、手势行的绑定。原文件、插件和节点仍保留。

动作配置中可用撤销、重做处理绑定整理，但保存基础设置或编辑应用、手势等可能清空历史。撤销文件导入后的绑定，不删除新建的启动项。

原文件搬动或需要改启动参数时，到 **快速启动 → 自定义启动** 编辑原项，再返回各入口测试。

## 场景：一次整理项目内容

在启动窗创建“项目 A”，从资源管理器批量拖入目录和文档，再从节点面板拖入编辑器与插件工具。选出最高频目录，继续拖到主面板全局区和轮盘常用方向；暂时少用的内容留在分类中。

## 拖不进去时按顺序检查

1. 目标是否正确，尤其分类、应用范围、页、轨迹与修饰键行。
2. 指定动作槽位是否一次只拖入一个本地项目。
3. 是否仍有未完成的编辑、选择或导入窗口。
4. 节点是否可执行、插件是否运行、原路径是否存在。
5. 配置目标是否在拖拽期间切换，必要时重新选定落点再拖。
6. 新内容是否需要刷新节点面板。

普通桌面程序能否接收 MioKit 节点，取决于它自身的支持；不能将节点面板拖拽宣传为任意软件都能识别的通用文件拖拽。
