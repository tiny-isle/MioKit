# 搜索作用域与触发词

搜索作用域让搜索框专注于某一项功能。例如，进入计算功能后，后续输入作为表达式处理；进入文件搜索插件提供的范围后，按该范围的搜索规则查找内容。

界面中的 **搜索命令** 用于管理这些入口的触发词。这里的 Command 是搜索作用域的入口名称，不是直接输入任意终端命令执行。

## 使用前提

目标功能必须提供可进入的搜索作用域，插件需要已安装并运行。不是所有可执行节点都有专用搜索范围，也不是所有插件都提供触发词。

同一个功能可以提供系统触发词，也可以允许用户添加自己的词。系统词只读显示，自定义词在编辑窗口中管理。

## 用完整触发词进入

以当前已启用且提供 `calc` 的计算功能为例：

1. 按 `Alt + Space` 打开搜索框。
2. 输入 `calc`。
3. 按 `Tab` 进入对应功能。
4. 输入 `12 * 8`，查看该功能给出的结果和操作。

```text
calc → Tab → 12 * 8
```

触发词以本机已启用功能实际提供的值为准。安装了其他计算插件，不表示它一定使用同一个词。

## 用灰色补全缩短输入

只输入触发词前几个字母时，输入框可能显示灰色补全。补全指向目标功能时，直接按 `Tab` 就能进入。

这里没有额外的“选择补全列表”步骤。如果短前缀补全到另一个功能，就继续输入完整触发词，再按 `Tab`。多个功能名称相近时，完整词更容易确认进入范围。

## 不记得触发词时使用斜杠

1. 在普通搜索中输入 `/`。
2. 查看当前可进入的搜索作用域。
3. 继续在 `/` 后输入名称，缩小结果范围。
4. 选中目标结果，按 `Enter` 进入。

这个列表用于发现搜索范围，不是全部可执行节点清单。需要查找可拖拽的动作时，使用[节点面板](drag-and-drop.md)。

## 返回普通搜索

清空当前搜索输入后按 `Backspace`，即可解除当前搜索范围。若还有剪贴板上下文，会先解除该上下文；文本还可能填入搜索框，此时清空新输入后再按 `Backspace` 返回。

只关闭窗口与返回普通搜索不是同一操作。附加面板在隐藏后保留多久，由搜索框设置控制；需要明确切换范围时，使用上述返回步骤。

## 添加自己的触发词

1. 右键托盘图标打开 **设置 → 搜索命令**。
2. 搜索目标功能，打开对应的编辑窗口。
3. 在用户命令区域输入新词并添加，例如 `my-calc`。
4. 点击 **保存**，确认没有格式或冲突错误。
5. 回到搜索框，输入新词并按 `Tab`，检查进入的功能。

| 规则 | 说明 |
| --- | --- |
| 小写英文单词 | 不能以中文、空格或任意符号作为触发词 |
| 单个 `-` 或 `_` 分隔 | 例如 `my-calc`、`file_find` |
| 不重复系统词 | 已是该功能系统词的内容无需再次添加 |
| 避免跨功能冲突 | 其他功能已使用的词应换一个名称，按保存提示处理 |
| 保存后生效 | 编辑草稿没有保存时，不应认为新词已可用 |

移除不需要的用户词后也要保存，再测试系统词或保留的用户词仍可进入。系统提供的原有触发词与用户词分开管理。

## 场景：区分多个文件搜索范围

当一个插件提供多个范围时，可以为不同范围设置容易辨认的触发词。输入词并按 `Tab` 后，再输入文件名，避免在所有搜索结果中混找。

范围的过滤规则和结果处理仍由对应插件决定。为范围改触发词，不会自动改变它索引哪些文件。

## 常见问题

**输入词后为什么仍是普通搜索？** 需要按 `Tab` 进入，并确认对应功能正在运行、词已保存。

**进入了另一个功能？** 短前缀可能补全到其他命令，输入完整词再试；检查自定义命名和冲突提示。

**设置中没有可配置功能？** 当前没有加载提供搜索作用域的功能，先检查相关插件及其使用前提。

**为什么主面板或启动窗不在斜杠列表中？** 列表展示搜索作用域，不按所有窗口或动作分类。它们使用各自的呼出方式。
