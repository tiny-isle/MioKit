# 全局搜索与快捷操作

搜索框提供无需提前整理的调用入口。默认按 `Alt + Space` 呼出，输入几个字，选择结果后按 `Enter` 执行。适合知道名称、暂时找不到入口，或偶尔才会使用的内容。

## 可以搜索什么

| 内容 | 来源与前提 |
| --- | --- |
| 桌面应用 | 快速启动的应用扫描结果 |
| Microsoft Store 应用 | 应用扫描中收录的商店应用 |
| Windows 设置和控制面板 | 系统扫描中可用的入口 |
| 自己添加的文件或文件夹 | 已保存为自定义启动项 |
| 启动组合 | 在自定义启动中创建的组合 |
| 插件功能或条目 | 插件运行，且功能支持提供搜索结果 |
| 文件系统中的其他内容 | 由当前启用的文件搜索功能或插件提供 |

搜索框不默认等于全盘文件索引。一个未收录的文档能否被找到，需要看文件搜索插件的范围；想固定调用它，可以直接拖入启动窗或自定义启动页收录。

## 从呼出到执行

1. 按 `Alt + Space` 打开搜索框。
2. 输入应用、文件或功能名称。可以尝试中文、拼音、首字母缩写、中英文混合，以及自己设置的别名。
3. 用 `↑` / `↓` 选择结果，检查名称、来源和说明，避免同名内容混淆。
4. 按 `Enter`，或点击目标结果执行。
5. 在普通结果列表中按 `Esc` 可以收起搜索框；有菜单或对话框时，会先关闭当前菜单或对话框。

选择不同节点，结果可能是启动程序、打开目录、进入管理窗口或执行插件动作。先确认目标属于哪个功能，再决定是否执行。

## 使用结果的更多操作

右键结果可以查看它提供的操作。也可以选中结果后按 `Alt` 打开操作面板，输入文字筛选，再用方向键和回车执行。

| 常见操作 | 使用目的 |
| --- | --- |
| 打开所在目录 | 查看程序或文件的位置 |
| 复制路径 | 将路径用于文档、命令或其他软件 |
| 设置别名 | 用自己记得住的词查找该内容 |
| 设置快捷键 | 将少量高频节点直接绑定到组合键 |
| 固定到首页 | 不输入关键词时也能访问 |
| 忽略搜索结果 | 让不需要的节点退出搜索匹配 |
| 插件附加操作 | 对当前结果执行插件支持的处理 |

实际菜单由结果与节点能力决定，不是每个结果都有表中所有操作。结果默认执行与附加操作也可能不同，例如默认打开内容，附加操作则复制路径。

## 首页、固定项与最近使用

首页用于收纳无需再次输入即可点选的内容。将常用项固定后，可以在首页访问并整理固定项顺序；开启 **显示最近使用** 后，呼出时还可查看最近访问的节点。

整理固定项时，在首页用左键按住已固定卡片拖动，移到需要的位置后松开。完成后重新查看首页，确认顺序保存；最近使用区域不按这种方式手动排序。

固定首页与关键词匹配分别管理。固定某个节点，不表示它在所有关键词搜索中必定排在第一；调整固定项顺序也不等于修改搜索排序。

开启忽略搜索后，节点不再参与普通搜索匹配。对快速启动项而言，固定与忽略可以分别设置，固定项仍可能显示在首页。需要恢复搜索时，到 **设置 → 已忽略节点** 取消忽略，或在相应扫描列表关闭 **忽略搜索**。

## 用别名缩短查找过程

给一个名称较长或不容易记住的应用设置简短别名，例如给编辑器添加“写代码”。在应用扫描或系统扫描的编辑窗口输入别名后按 `Enter` 添加，再点击 **保存**，回搜索框测试。

别名是用于匹配的名称，不会重命名磁盘文件，也不一定改变其他面板中单独设置的显示名称。

## 专用搜索与剪贴板

输入完整触发词后按 `Tab`，可以进入支持的专用搜索作用域。输入 `/` 能查看可进入的作用域；具体方法见[搜索作用域与触发词](search-commands.md)。

搜索框还可以根据有效的剪贴板上下文显示相关内容。是否出现、能对其执行什么操作，取决于当前设置和支持该内容的功能；它与插件提供的历史剪贴板列表用途不同。详见[操作目标与上下文](context.md)。

## 常用配置

在 **设置 → 搜索框设置** 中修改呼出快捷键、窗口位置、图标、欢迎语、最近使用和标题显示。快捷键在录入面板保存，普通设置项按界面直接保存。完整选项见[设置与个性化](personalization.md)。

修改呼出快捷键后，先用新组合测试。全屏环境不响应时，还需要检查基础设置中的 **全屏免打扰**。

## 场景：临时找到系统设置

需要调整一个不常用的 Windows 设置时，先搜索设置名称，检查结果确实来自系统入口，再执行打开。偶尔使用的设置继续通过搜索查找；频繁使用的设置可以固定到首页，或将可执行节点加入主面板。

## 找不到或执行失败时

1. 先清空输入，换完整名称或别名，确认当前是否仍在专用搜索范围中。
2. 应用到应用扫描页查找；便携软件检查扫描目录是否正确并已重新扫描。
3. 文件检查是否已手动收录，或是否处于所用文件搜索插件的范围。
4. 插件结果检查插件运行状态、首次配置和已创建条目。
5. 检查已忽略节点与扫描过滤规则。
6. 找到了但打不开时，检查原路径、运行权限和插件错误提示；不要只通过重复更换入口排查。
