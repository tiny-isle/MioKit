# 节点与动作配置

MioKit 中的应用、文件、文件夹、系统入口和插件功能，都可以作为“节点”使用。只要节点支持执行，就可以把它放到启动窗、主面板、轮盘或鼠标手势中，用适合自己的方式调用同一个功能。

例如，项目文件夹既可以通过搜索打开，也可以放进启动窗的“工作”分类、主面板的一个格子，或绑定到轮盘扇区。插件提供的可执行功能也可以这样配置，不局限于启动应用。

## 先选一种使用方式

| 入口 | 怎样使用 | 适合什么场景 |
| --- | --- | --- |
| 搜索框 | 输入名称、拼音或别名，选择结果执行 | 临时查找、不想提前整理的功能 |
| [启动窗](launcher.md) | 默认 `Ctrl + Space` 呼出，按分类点击图标执行 | 整理应用、项目资料和常用工具 |
| [主面板](main-panel.md) | 默认按鼠标中键呼出，点击格子执行 | 全局常用操作与当前软件的专属操作 |
| [轮盘](radial-menu.md) | 按住鼠标按钮拖动，指向目标后松开 | 鼠标操作过程中快速选择动作 |
| [鼠标手势](mouse-gestures.md) | 按住鼠标按钮画出轨迹，松开执行 | 已形成习惯、不需要看菜单的高频操作 |
| 节点快捷键 | 为支持快捷键的节点录入组合键 | 少量最常用的功能 |

启动窗按自己创建的分类整理内容。主面板、轮盘和手势还可以根据正在操作的应用切换动作。

## 打开动作配置

1. 在 Windows 通知区域找到 MioKit 托盘图标。
2. 右键图标，选择 **动作配置**。
3. 在窗口上方选择 **主面板**、**轮盘** 或 **鼠标手势**。
4. 切换 **节点绑定** 和 **基础设置**：前者决定执行什么，后者决定怎样呼出以及界面如何显示。

主面板标题栏的设置按钮也可以打开对应配置。启动窗的呼出与窗口行为在 **设置中心 → 启动窗设置** 中调整，分类和启动项直接在启动窗内整理。

![动作配置总览](../../assets/images/action-editor-overview.png)

## 绑定一个节点

以主面板为例：

1. 进入 **主面板 → 节点绑定**，在左侧选择 **全局**。
2. 点击一个空格子，在绑定属性中点击 **选择节点**；也可以双击格子直接打开选择窗口。
3. 搜索节点名称、描述或来源，选择需要的节点。
4. 绑定成功后，格子会显示节点名称和图标。
5. 呼出主面板，点击该格子检查执行效果。

也可以点击右上角 **全部节点**，在打开的置顶“节点面板”中找到节点，再拖到目标格子。轮盘拖到扇区，手势拖到对应的修饰键绑定行，操作方法相同，详见[拖拽与节点面板](drag-and-drop.md)。

选择器只会提供当前可用于执行的节点。如果要添加文件或文件夹，可以直接从资源管理器拖入；未收录的路径会提示先添加为启动项。

### 更换与移除一个入口

1. 选中已经绑定的格子、扇区或手势行。
2. 在绑定属性中点击 **更换节点** 选择新动作，或点击 **清除绑定** 移除当前入口。
3. 回到日常使用的软件，重新触发并检查结果。

清除绑定会保留原节点和文件。清除轮盘或手势的应用专属绑定后，可能重新使用全局同一位置或组合的动作；如果仍触发了动作，应继续检查全局绑定。

## 全局、通用与应用专属

### 主面板：两个区域同时显示

主面板上方是 **全局区**，下方是 **应用区**：

- **全局**：所有应用共用，适合放剪贴板、项目入口等常用功能。
- **通用**：没有匹配专属配置时，应用区使用这一组内容。
- **应用专属**：匹配到某个应用时，应用区显示它自己的动作页。需要常驻的功能应放在全局区。

### 轮盘和手势：应用绑定优先

轮盘会优先使用应用在相应槽位上的绑定，没有应用绑定的槽位使用全局配置。

手势会优先使用该应用的“手势 + 修饰键组合”绑定，未设置时查找全局的同一组合。例如，`Ctrl + 上` 未绑定时，不会自动改为执行不带 Ctrl 的“上”动作。

应用编辑页展示的是该应用自己设置的绑定。因此，编辑页中某处为空，实际触发时仍可能使用全局动作。

## 添加应用专属配置

1. 先运行要配置的软件，方便在程序列表中选择。
2. 在动作配置左下角点击 **添加应用**。
3. 填写便于识别的 **应用名称**，例如“浏览器”或“代码编辑器”。
4. 点击 **选择进程**，从当前运行的程序中选择；也可以手动输入进程名。至少添加一个匹配进程。
5. 如需让其他程序共用这组动作，使用 **选择关联程序** 添加它们。关联程序已有独立配置时，优先使用独立配置。
6. 点击 **添加应用** 保存，再分别到三个模块中配置需要的节点。主面板若还没有动作页，先新增一页。
7. 切回目标软件，从目标软件中呼出主面板、轮盘或手势，检查是否匹配。

应用资料由三个模块共享，节点绑定分别配置。添加一次应用后，无需在每个模块重新添加进程。

鼠标呼出主面板、轮盘或开始手势时，先把指针放在要操作的软件窗口内；键盘呼出主面板时，先激活目标软件。应用配置按本次目标匹配，共用配置不会把动作对象改成另一个软件。

![选择匹配进程](../../assets/images/action-application.png)

左下角的编辑按钮可以修改当前应用。删除应用会同时删除它在主面板、轮盘和手势中的专属配置；这与移除单个节点绑定不同。

## 哪些操作需要保存

| 操作 | 如何生效 |
| --- | --- |
| 选择或拖入节点、清除绑定、移动绑定、动作页整理 | 操作成功后直接保存 |
| 基础设置中的触发方式、布局、识别参数等 | 点击底部 **保存设置** |
| 绑定属性中的名称、描述、图标 | 点击该属性区域的 **保存** |
| 主面板快捷键 | 在快捷键录入面板中单独保存 |
| 设置中心中的启动窗开关和选项 | 修改后直接保存；快捷键仍需在录入面板确认 |
| 新建或修改应用、录制手势 | 在对应窗口中确认保存 |

有未保存的改动时，切换页面会提示处理。不要把布局预览当作已经应用到实际窗口；保存成功后再试用。

节点绑定页提供 **撤销 / 重做**，可使用 `Ctrl + Z` 撤销、`Ctrl + Y` 或 `Ctrl + Shift + Z` 重做。它主要用于当前动作配置窗口内的节点绑定、动作页和子轮盘整理；保存基础设置、修改应用资料或编辑手势本身后，历史会重置，以按钮可用状态为准。有未保存草稿或正在输入、操作对话框时，先处理当前编辑。

通过拖入文件新建的启动节点会保留，撤销绑定不会把它从启动库中删除。

## 绑定与原节点的关系

同一个节点可以放在多个入口中。清除格子、扇区或手势的绑定，只是移除这个入口；不会卸载插件，也不会删除原文件。

主面板、轮盘中可单独设置显示名称和图标，方便把较长名称改成“项目目录”“常用输入”等。节点实际执行什么，仍由原节点决定。

如果插件未加载或节点已删除，原位置可能提示 **节点暂不可用**。先恢复插件或原节点，再重新打开；确实不再使用时，清除或更换绑定。

## 场景：同一个文件夹，多种调用方式

先把项目目录拖到启动窗分类，完成新路径收录，再从节点面板找到这个目录。将它拖到主面板全局格子、轮盘的常用方向，或手势的无修饰键行。

之后既可以分类点选，也可以通过鼠标触发打开。想调整入口布局，只移动或清除对应绑定；想修改启动项的路径，则到[自定义启动](quick-launch.md)编辑原节点。

## 常见问题

**选择器里找不到节点？** 先清空关键词和筛选条件，确认对应插件已运行、内容已在插件内创建，且节点支持执行，再重新打开选择器或刷新节点面板。

**添加应用提示进程已归属其他配置？** 同一进程不能重复作为两个应用的匹配进程，同一个关联程序也不能重复归属。编辑已有配置，或先从旧配置移除该进程，再添加到新配置。

**应用配置添加成功，主面板却没有格子可填？** 选择该应用，在主面板节点绑定页先新增一个动作页，再选择空格子绑定。

**在编辑窗口中测试，匹配到的应用不对？** 先保存并关闭当前编辑，切回真正要使用的软件，再呼出或绘制手势；匹配依据当时的目标应用。
