# 快速启动与自定义启动

快速启动负责收录可搜索、可绑定的应用与路径。启动窗、主面板、轮盘和手势可以复用这些节点；想修改启动参数或整理收录内容时，前往 **设置中心 → 快速启动**。

## 管理应用与系统入口

- **应用扫描**：查看桌面应用与 Microsoft Store 应用，搜索和筛选需要的启动项。
- **系统扫描**：查看控制面板和 Windows 设置入口。
- **自定义启动**：管理自己添加的文件、文件夹与启动组合。
- **扫描配置**：设置自定义扫描目录、排除关键词和忽略文件类型，并按需要重新扫描。

如果应用没有出现在搜索结果中，可以先在应用扫描页查找；未收录时，添加其所在目录并重新扫描，或者直接把程序文件作为自定义启动项添加。

### 调整已经收录的应用

在 **应用扫描** 中，可以按名称、路径或别名搜索，并筛选 Win32 或商店应用；**系统扫描** 支持按名称或别名查找。列表中的 **忽略搜索** 和 **固定首页** 开关可直接调整搜索行为。

点击对应行的编辑按钮，可以添加别名和说明。别名输入后按 `Enter` 添加，再点击 **保存**。例如给编辑器添加“写代码”别名，之后就可以用这个词搜索。

想恢复被忽略的应用时，回到对应列表关闭 **忽略搜索**，或到[已忽略节点](../user-guide.md#恢复被忽略的节点)恢复。

## 添加文件或文件夹

1. 打开 **快速启动 → 自定义启动**。
2. 将文件或文件夹拖入页面，可以一次拖入多个。
3. 在编辑窗口检查每项的名称和路径；多项内容通过标签切换查看，需要时使用路径旁的浏览按钮重新选择。
4. 文件启动项还可设置 **启动参数**、**工作目录** 和 **以管理员身份运行**。
5. 按需要填写描述，设置是否 **固定到首页**、是否 **忽略搜索结果**，然后点击 **保存**；批量添加时点击 **保存全部（数量）**。
6. 在搜索框中查找该节点并执行，确认启动效果。

不方便拖入时，点击右上角 **添加 → 添加文件 / 添加文件夹**，先进入编辑表单。填写名称与路径，或点击路径右侧的浏览按钮选择本地位置，再点击 **保存**。

固定到首页便于从搜索框首页访问，不会改变关键词搜索结果的顺序；忽略搜索结果控制是否参加搜索匹配，固定项仍可显示在首页。

![自定义启动编辑](../../assets/images/custom-launch.png)

也可以先从启动窗或动作配置拖入本地路径，再到这里补充参数。添加完成后，节点可通过节点面板拖到其他入口。

## 修改、测试和删除启动项

在 **自定义启动** 列表中搜索名称，或按文件、文件夹、组合筛选：

1. 点击该行 **启动**，直接检查当前配置的启动效果。
2. 点击 **编辑**，修改名称、路径，以及适用的启动参数和工作目录。
3. 保存后再次点击 **启动**，再从原来的启动窗或动作绑定中执行检查。

文件移动到其他位置后，可以编辑原启动项，通过路径旁的浏览按钮重新选择，保存并测试。无需为了改路径重新创建同名节点。

点击 **删除** 后按确认窗口完成移除。删除自定义启动项不会删除磁盘文件或文件夹；删除组合不会删除成员。其他位置引用这个节点的入口可能变为不可用，按需要清除或更换绑定。只想从某个面板移走时，直接移除那个入口即可。

## 创建启动组合

如果每天都要打开同一组工具，可以把已有启动节点组成一个入口。

1. 在 **自定义启动** 页面的 **添加** 菜单中选择 **创建组合**；空列表引导中也提供这个按钮。
2. 搜索并勾选需要一起启动的节点。成员来自快速启动库，包括已收录的应用、系统入口、手动文件或文件夹节点，不能选择另一个组合。
3. 进入下一步，设置组合名称，例如“项目 A 开工”。
4. 按需要设置描述、图标及首页选项，点击 **创建组合**。
5. 从搜索框执行一次检查；随后可以把组合放入启动窗，或绑定到主面板、轮盘、手势。

![创建启动组合](../../assets/images/launch-group.png)

执行组合时会同时发起成员的启动操作，不保证软件完成打开的先后顺序，也不提供逐步等待或延迟执行。成员仍可单独使用，删除组合不会删除成员。

### 调整组合成员

点击组合所在行的 **编辑**，先进入成员选择页，取消旧成员、加入新成员，再到下一步修改名称和图标，点击 **保存修改**。

成员被删除后，组合会显示失效数量；编辑时标为 **已失效**，应先移除或替换这些成员再继续。保存后用该行 **启动** 按钮检查。

## 添加自定义扫描目录

1. 进入 **快速启动 → 扫描配置**。
2. 在 **自定义扫描目录** 中选择、输入或拖入文件夹，多个文件夹可以一起拖入。
3. 如需减少无关项目，添加 **排除关键词** 或 **忽略文件类型**。
4. 点击 **重新扫描**，等待完成，再到应用扫描或搜索框查看结果。

扫描目录和过滤规则在添加、移除后直接保存；**重新扫描** 用于按这些规则重新发现内容。

例如，把集中存放便携软件的目录加入扫描，之后可通过搜索查找发现的启动项。只想打开该目录本身时，把它添加为自定义文件夹节点即可。

### 减少不需要的扫描结果

- **排除关键词**：例如添加“卸载”，名称包含该词的扫描项会被过滤，英文不区分大小写。
- **忽略文件类型**：填写扩展名，例如 `tmp`，页面会补成 `.tmp`。
- **只隐藏一项**：在应用或系统扫描列表开启该项的 **忽略搜索**，无需扩大扫描过滤范围。

目录或过滤规则改变后，点击 **重新扫描**，再检查扫描列表和搜索结果。想找回被规则排除的内容，先移除相应规则再扫描。

## 场景：一个入口打开工作环境

先收录编辑器、项目目录和需求文档，再建立“项目 A 开工”组合。早上从启动窗点击组合，或用轮盘、手势调用它，就能一起发起这些启动操作。项目中的单个目录和文档仍可放在旁边，方便单独打开。

## 常见问题

**扫描目录加了，为什么搜不到？** 确认规则已添加并完成重新扫描，再到应用扫描列表查找，检查排除关键词、忽略文件类型以及该项的忽略搜索开关。

**有些内容不在组合成员列表里？** 组合只选择快速启动库中支持的成员。插件工具可以单独放进启动窗或动作入口；另一个组合也不能作为成员加入。

**文件能手动打开，通过节点却失败？** 先在自定义启动中点击启动，核对路径仍有效，检查文件项的参数、工作目录和运行权限设置。修正保存后再测试绑定入口。

**把文件夹拖进扫描配置后，没有出现打开文件夹的节点？** 扫描目录用于发现内部内容。要打开文件夹本身，请把它添加到自定义启动或直接拖到启动窗。
