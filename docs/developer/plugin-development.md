## 3. 插件生命周期

插件生命周期的准确接口名称和调用时机待补充。文档最终应覆盖：

1. 发现和读取插件清单。
2. 校验插件兼容性与依赖。
3. 加载插件。
4. 初始化宿主服务。
5. 响应插件功能调用。
6. 停用和释放资源。

插件应在停止或卸载时释放订阅、计时器、文件句柄和其他外部资源。

## 4. 注册功能

待补充：插件如何向 MioKit 注册命令、页面、搜索项、服务或其他扩展点。

注册设计应遵循以下原则：

- 使用稳定且面向意图的接口，而不是依赖宿主内部实现。
- 通过依赖注入获取宿主能力。
- 不直接依赖具体 UI 框架类型。
- 在插件清单中声明必要的能力和依赖。

## 5. 配置与存储

插件的配置、脚本和持久化行为应通过抽象服务完成，不应把具体存储引擎类型暴露给插件业务逻辑。

准确的配置接口、数据目录和迁移策略待补充，相关边界请先阅读[架构原则](architecture.md)。

## 6. 调试

开发阶段建议记录插件加载、注册、调用和释放过程中的可诊断信息。调试、打包和发布流程见[调试、打包与发布](debugging-and-packaging.md)。
