# 插件提交检查清单

> 状态：草案；正式发布流程确定后持续更新。

## 功能与兼容性

- [ ] 插件功能和使用场景有清晰说明。
- [ ] 已声明支持的 MioKit 宿主版本。
- [ ] 已确认依赖的插件、运行时和宿主能力。
- [ ] 不依赖未公开或未稳定的内部 API。

## 工程质量

- [ ] 插件可以在干净环境中安装。
- [ ] 插件可以正常停用、卸载并释放资源。
- [ ] 配置和持久化行为使用公开抽象完成。
- [ ] 没有把具体 UI 框架类型泄漏到核心逻辑。
- [ ] 已处理加载失败、依赖缺失和配置损坏等情况。

## 安全与隐私

- [ ] 包内不包含密钥、令牌、个人路径或调试日志。
- [ ] 已说明网络访问、文件访问和其他外部能力需求。
- [ ] 插件只请求完成其功能所需的能力。

## 文档与发布

- [ ] 已填写有效的插件清单。
- [ ] 已提供安装、使用和卸载说明。
- [ ] 已提供版本变更说明。
- [ ] 已完成[调试、打包与发布](debugging-and-packaging.md)中的发布前检查。
